#TaskFlow API

RESTful Task Management API built with Java, Spring Boot 3, Spring Security, JWT, and MySQL.

Note: The live demo (previously hosted on Railway) is currently offline. Clone and run locally using the instructions below.


Tech Stack

Java 17 + Spring Boot 3
Spring Security + JWT Authentication
MySQL + Spring Data JPA
Swagger UI (API Documentation)
Deployed on Railway (currently not live — see note above)
