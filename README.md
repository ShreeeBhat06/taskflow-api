# 🚀 TaskFlow API

A RESTful Task Management API built using **Java 17**, **Spring Boot 3**, **Spring Security**, **JWT Authentication**, and **MySQL**.

> **Note:** The live demo (previously hosted on Railway) is currently offline. Clone the repository and run it locally.

## ✨ Features

- JWT Authentication & Authorization
- User Registration & Login
- CRUD Operations for Tasks
- Spring Security
- MySQL with Spring Data JPA
- Swagger UI Documentation

## 🛠️ Tech Stack

- Java 17
- Spring Boot 3
- Spring Security
- JWT
- Spring Data JPA
- MySQL
- Maven
- Swagger UI

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/taskflow-api.git
cd taskflow-api
```

### Run the Application

```bash
mvn spring-boot:run
```

The application will be available at:

```
http://localhost:8080
```

## 📖 API Documentation

Swagger UI:

```
http://localhost:8080/swagger-ui/index.html
```
